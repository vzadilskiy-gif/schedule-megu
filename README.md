# schedule-megu

Мінімалістичний тижневий розклад пар. Одна сторінка без залежностей: index.html.

Можливості

	•	ручне додавання, зміна й видалення пар
	•	типовий час за номером пари (1–6), який можна змінити
	•	чисельник і знаменник з фільтром
	•	вигляди «Сьогодні» і «Тиждень», позначки «зараз» і «далі»
	•	попередження, якщо дві пари перетинаються за часом
	•	світла й темна тема за налаштуваннями системи

Запуск

Відкрий index.html у браузері. Для GitHub Pages увімкни Pages для гілки main (корінь репозиторію).

Зберігання даних

Окремо від Claude сторінка зберігає розклад у localStorage браузера. Дані видно лише на тому пристрої, де їх введено. Спільне редагування (власник змінює, інші бачать наживо) працює тільки в сторінці, опублікованій у Claude, бо використовує її сховище.
